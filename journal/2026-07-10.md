-√(T/365) 里的天数 = "距离到期还剩多少时间"

这是一段到某个日历日期（到期日）的时长。期权的时间价值是按日历时间流逝的——到期日是个日历上的死日子，周末照样在往到期日走，星期五到星期一，三天时间价值该扣就扣。所以"还剩多久" = 日历天数 / 365（一年 365 个日历日）。

> T 回答的是：离到期还有多长的路。 路是按日历量的。

-√242 里的天数 = "一年有多少个收益率样本"

HV 是从每日收益率估出来的。你先算出日波动率 σ_daily，要年化，就得乘 √(一年有多少个观测)。周末市场不开，没有收益率数据——一年只有 ~242 个交易日产生了 242 个收益率样本。所以是 √242，不是 √365。

> 242 回答的是：一年攒了多少个数据点。 数据点只在开市日产生。

σ 永远用数据点不是到期时长

如果你 HV 硬用 √365 年化，等于假装周末也在波动，会把波动率高估约 23%：
√365 / √242 = √(365/242) = √1.51 ≈ 1.23
-365 是"还剩多少路"（日历时长），242 是"攒了多少数据点"（收益样本，看交易日）。一个量路，一个数点，别混。


| 量 | 用哪个 | 为什么 |
|----|--------|--------|
| 到期时间 T | 365 | 时长 |
| 贴现因子 e^(−rT) | 365 | 时长 |
| 塞进公式的 σ | 242 | 是"被年化的波动率"，不是时长 |
| 到期前总预期波动 = S·σ·√(T/365) | 混用 | √时长用365，σ用242 |
| 单日预期波动 = S·σ/√242 | 242 | "一天"= 一个交易日样本 |

-盘口里的买量/卖量

- 买量 = 当前最优买价（bid）上，还挂着没成交的买单数量
- 卖量 = 当前最优卖价（ask）上，还挂着没成交的卖单数量

它们是在排队等成交的单子，代表"这个价位上现在有多少货可买/可卖"= 可用流动性。还没成交，成交了就从盘口消失了。

别和这几个混

| 字段 | 含义 | 性质 |
|------|------|------|
| 买量/卖量 | 最优价上挂着的单量 | 挂单（等成交） |
| 成交量 | 今日累计成交手数 | 已成交（累计） |
| 现手 | 最近一笔成交的手数 | 已成交（单笔） |
| 持仓量 | 未平仓合约总数 | 存量 |

核心思路

组合单 = 一个订单、一个净价、两腿捆绑成交。你不再分别挂两条腿的价，而是挂"整个价差"的净价。够这个净价 → 两腿同时成交；不够 → 挂着，永远不会只成交一腿（今天的错，用工具直接根除）。

第一步：算净价的中间价（需要 4 个数）

你要"买回"这个价差（买 P2225、卖 P2200）。要凑齐两条腿各自的 bid/ask。假设盘口是（你用真实数替换）：

|-----|-----|-----|
| P2225（要买平） | 12 | 13 |
| P2200（要卖平） | 9 | 10 |

买回价差的净价范围：
最贵（扫市价）= 买腿ask − 卖腿bid = 13 − 9 = 4.0   ← 立即成交，地板价
最便宜（最优）= 买腿bid − 卖腿ask = 12 − 10 = 2.0   ← 未必成交
中间价（mid）= (4.0 + 2.0) / 2 = 3.0

第二步：挂组合限价单

在文华财经用组合下单 / 价差单，建一条腿：
买开→买平 P2225  ×1
卖开→卖平 P2200  ×1
订单类型：限价
净价：3.0（挂 mid）  或  3.5（略让一点，更快成交）

第三步：会发生什么

- 市场净价 ≤ 3.0 → 两腿瞬间一起成交，你花 ¥30 买回 → 盈利 ¥30（vs 扫市价 ¥20）
- 一直到不了 3.0 → 单子挂着等，你手上始终是完整价差，零裸露
- 想快点 → 把净价从 3.0 提到 3.5（成本 ¥35 → 盈利 ¥25），提高成交概率

第四步：死线 fallback（关键）

挂 mid 是为了多赚，但不能挂到过事件。规则：

> 到夜盘收盘前还没成交 → 撤单，净价直接挂 4.0（扫市价）成交，¥20 也收，不裸空过夜。

限价保利，死线保命。 二者都要。

-一句话公式（背下来）

> 平价差净价：买腿ask − 卖腿bid = 地板；买腿bid − 卖腿ask = 天花板；两者取中 = mid。挂 mid 或 mid+一点，够不到就到点扫市价。

这样你今天所有的坑一次全堵上：组合单 = 不裸露（顺序问题消失）+ 挂中间价（少付 bid/ask）+ 死线（不扛事件）。 三合一。

-考虑自动化限价监控系统（legging out 机制）

留着空腿 P2225、撤掉买腿，如果菜粕小幅反弹 → P2225 贬值 → 你买回更便宜 → 比现在双腿平多赚一点。这个机制没错，专业做市/方向交易确实这么干。

## 讨论问题

1. 事件前必须平仓吗？如果是，每次 USDA / 每周发报告都要平掉吗？一个信用价差持仓顶多十来天，岂不老在提前平？

如果每个事件都一刀切平，信用价差顶多十来天、老撞上报告，那你永远吃不到完整 theta，策略就废了。 所以规则不该是"见事件就平"。真正的判据是两层：

第一层：不是所有事件都算数——只看"对你这个品种高影响"的事件
- USDA WASDE 对菜粕/豆粕/玉米/棉花是高影响（你今天中招）。对金属、能源仓位它啥都不是。
- 先纠正你一个事实：WASDE 是月度（一年 12 次），不是每周。你说的"每周报告"是出口销售（周四）+ 作物进度（周一），那些是低影响。所以真正要防的高影响事件，一个十来天的价差通常只撞上 0-1 个，不是每周都躲。

第二层：撞上了也不一定平——比"事件预期波动 vs 你的缓冲"
这是今天最该升级进规则的东西：
事件预期波动（历史 or IV 反推的跨式价）  vs  你卖腿的 OTM 缓冲
- 缓冲 ≫ 预期波动（比如缓冲是预期的 2 倍）+ 已经吃了不少 theta → 可以持有，事件大概率打不穿卖腿。今天菜粕 OTM 4.2%，USDA 典型 ±3%——其实典型波动打不穿你。你今天该平，是因为缓冲只比预期厚一点点、尾部能吃穿，且利润才 ¥25 不值得赌尾巴。
- 缓冲 ≈ 或 < 预期波动 → 平（或移仓）。这才是"平"的真正触发。
- 已经到 50% 止盈 → 无所谓事件，50% 规则先把它平了。

所以规则从"D-0 高影响 → 平"升级成：

▎ D-0 高影响事件（对本品种）+ 缓冲 < 事件预期波动 → 平。缓冲远厚于预期波动可持有。已达 50% 止盈则照常平。

进场那条不变：不在高影响事件前新开卖方——因为你还没攒任何 theta，纯裸接事件风险，没 edge。

→ 这样你不会"老在提前平"：多数报告低影响、多数厚缓冲仓位能扛，只有"薄缓冲 + 真高影响"才平。

2. 追动量 = 赌博，那追趋势也是赌博吗？

关键不在"动量"还是"趋势"这两个词，在于——有没有可验证的 edge + 风控框架。

裸猜方向 = 赌博，不管你叫它动量还是趋势。"它涨了所以会继续涨""我觉得会反弹"——没有规则、没有止损、没有 edge 度量，就是赌。你甲醇那次就是这个。

但系统化趋势跟踪 = 真策略（有正期望的实证）。CTA/管理期货几十年就靠它。它赚钱不是因为能预测方向，而是因为：
1. 机械规则（突破、均线交叉），不靠感觉
2. 快速砍损 + 让利润奔跑 → 正偏度：亏就亏小的，对了赚大的
3. 多品种分散 → 大数定律
4. edge 是统计出来的，几百笔样本验证，不是"我觉得"

区别一张表：
	  裸追（动量 / 趋势都算）	系统化趋势跟踪
依据	感觉、点位预测	       机械信号
止损	没有	            铁律，先定好
胜率	不知道	          已知（常 35-40%，靠大赢盈利）
本质	赌博	                    策略

诚实的补充：就算系统化趋势跟踪，也胜率很低（靠少数大赢），必须无差别执行所有信号（包括那一堆小亏），而且它是另一套学科，不是 Layer 1。你现在的 edge 是"卖贵了的期权 + 时间 + IV 回归"，方向不是你的饭碗。所以动量、趋势现在都不碰。

一句话：甲醇那笔是赌，不是因为它是"方向交易"，是因为它没有系统。方向可以做成策略，但要的是机械规则 + 止损 + edge 验证，不是一个念头。
