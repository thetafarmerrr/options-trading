你的问题：单边买 Put 怎么拉高 ATM IV？

IV 不是"平均数"——Put 买盘推高 OTM Put 价格，但会把整条波动率微笑往上平移，原因是做市商的对冲逻辑：

1. 客户大量买 Put → 做市商卖 Put → 做市商持有 Short Put 头寸
2. Short Put = Long Delta（做市商需要卖期货对冲）
3. 期货继续跌 → 做市商需要调 Delta → 卖更多期货 → 压低期货
4. 期货下跌 + Put 需求持续 → 做市商全曲线提价（不单是 Put 端）

所以 OTM Put 买盘会通过做市商的对冲链传到 ATM。你说的"IV"通常是 ATM IV——Scanner 和 Collector 报的都是 ATM 跨式反推的 IV。Put 端溢价能传导过来。

▎ 简版：Put 买盘 → 做市商对冲卖期货 → 期货承压 → 全曲线波动率上调 → ATM IV 也涨。

- 期货承压 → 全曲线波动率上调，这个是为什么

核心是杠杆效应——跌的时候 IV 跳得比涨的时候猛。两条传导链：

链 1：做市商对冲螺旋
客户买 Put → 做市商净空 Put（Long Delta）
→ 做市商卖期货对冲 Delta
→ 期货被压低
→ 期货跌了，做市商 Delta 变了（Gamma 效应）→ 需要卖更多期货
→ 期货继续承压
→ 更多人看到跌了，也来买 Put
→ 做市商：需求在涨 + 对冲成本在涨 → 全曲线上调 IV（不单是 Put 端）

链 2：恐慌定价
期货承压 = 有人在卖 = 看空信号
→ 持有黄金的人担心继续跌 → 买 Put 保护
→ Put 需求↑ → Put 价格↑ → OTM Put IV↑
→ 做市商看到 Put 端被买起来 → 上调全曲线报价
  （"跌的时候什么都会变贵"——你不会只调 Put 不调 Call）

两条链是同一件事的两个视角——杠杆效应的底层是"跌 = 不确定性放大 = 波动率贵"，做市商对冲只是实现这个定价的机械过程。

你引的 Sinclair 那句就是总结：「大的波动后面紧跟着大的波动」+「聚集在熊市更明显」——跌本身制造更多跌，波动本身制造更多波动。
