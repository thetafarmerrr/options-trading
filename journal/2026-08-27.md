## 讨论

### 倒挂动力学深挖（A 线程后续 · 教练措辞修正）
用户追问："修复启动 = 远月掉得比比例多，那修复期不也一直倒挂吗？" → **抓到我上一条措辞不准，收回修正**。

**① 措辞修正**："远月掉得比比例多"不准确。准确说法：远月掉得**比理性基准 0.85 多**（0.95 = 过度反应），但**绝对值上比近月少**（0.95 < 1.0）。两个"多"不是一回事。

**② 数值演示（倒挂是"粘"的）**：
```
修复前：近月 16.3%   远月 14.6%   价差 1.7pp（倒挂）
近月恐慌消退跌 1.8pp → 15.0%；远月只跟 0.95×1.8 = 1.71
修复后：近月 14.5%   远月 12.9%   价差 1.6pp（还是倒挂！）
```
每单位近月回落，价差只缩 0.05 单位（1−0.95）。**倒挂收窄很慢，闭合 = 近月回落到长期均值 = 恐慌走完的终点，不是起点。**

**③ 三个时点**（能不能卖）：
| 时点 | 性质 | 可卖？ |
|---|---|---|
| 闭合（近月≈远月）| 终点信号 | 能但溢价已没（双重滞后）|
| 收窄开始 | 顶点后的最早可测量确认 | 仍滞后 + 被法则①拦 |
| 见顶前置（判断"要开始回落"）| 理论最优 | 需主观判断 = 规则外的 edge |

**④ 为什么"收窄开始"不能进**：法则① 在倒挂消失前禁卖方，收窄≠解禁；且收窄是**结果**不是**拐点**——看到收窄时近月已跌一段，顶点已过，溢价已被吃一截。真正的卖点在顶点（恐慌最高、远月 IV 最贵），卖完恐慌消退远月过度回落。

**⑤ 规则内真实进场时点**：倒挂结束后的**第一个干净六步信号**。注意：倒挂结束只是"法则①解禁"，不构成进场信号；解禁后还要 IV-HV 剩溢价（大概率已缩到 <1% 不执行档）+ 趋势 + 事件 + 环境 + 盘口全绿。

**⑥ 诚实结论**：**倒挂修复溢价，规则内大概率吃不到** → "倒挂品种什么都不做"是教科书正确。今天 m/rm 全毙处理正确。

**⑦ 快照措辞重估**（待周五）：快照"Pro Farmer 创纪录→倒挂修复→卖方窗口可能提前开"——修复是终点信号不是起点信号，"提前开"措辞要打问号。

**⑧ 候选搁置**：倒挂修复进场的**可机械化程度**（前置判断 vs 规则捕捉的边界）→ 周六复盘讨论，记 MASTER_PLAN。

**⑨ 边界提醒**：追问"收窄时机"= 在设计一个新规则，属策略蔓延入口。理解窗口形状值得，今天不找进场点——那会变成分析瘫痪。

### 修复溢价 = 日历价差？（阶段归属 + 获利结构）
用户追问 ①"倒挂修复进场规则属于哪个阶段" ②"所以修复溢价的获利逻辑是日历价差？"

**① 阶段归属：分两层——读懂是 S1 的活，做是 S2 的活。**
- **读懂 = S1 认知考核 #5**（期限结构：能读倒挂/升水/微笑说出市场预期）。今天整个 A 线程+追问就是在练这条：m 倒挂 5 天 = 近月事件恐慌定价，做市商注意力在近月，Stein 过度反应。读出形状背后的事件 = 这条的毕业标准。
- **做 = S2 Layer 3 日历价差**。MASTER_PLAN line 72：日历价差 (calendar) | 卖近月买远月，赚期限结构回归。→ "倒挂修复进场规则"一旦具体化成"卖近买远赚修复回归"= 日历价差定义本身。排 **M13-15**，前置：**期限结构数据 ≥ 6 个月**（现在 Data 才 25/60，差得远）。所以现在不能设计细节——没数据验证 = 假精确。记搁置表，标 **S2 触发项**（触发 = S2 门全过 + 期限结构数据≥6月），周六复盘只查触发条件，不设计。

**② 修复溢价获利逻辑 = 日历价差？是——但日历价差是结构不是一种利润，装三种：**
| 利润来源 | 机制 | 需要倒挂吗 |
|---|---|---|
| theta carry | 卖近月收高 theta（近月短+贵），买远月付低 theta（远月长+便宜）→ 净收 | 不需要 |
| 结构收敛 | 价差收窄 = 近月掉得比远月多，短近腿赚 > 长远腿亏 | 是 |
| 恐慌溢价退潮 | 倒挂=近月被事件定价做贵，做空近月 = 收"恐慌定价"的钱 | 是 |

**修复溢价 = ②+③**（倒挂期间做空近月赌恐慌退潮）= 日历价差在倒挂期间最肥的一块。

**两句诚实：**
1. 这块利润没看起来大——价差"粘"（每单位近月回落只缩 0.05），纯收敛②很小；大头是③做空贵近月的恐慌溢价本身（=①的硬币另一面：近月贵才 theta 大，恐慌退潮贵也没了）
2. 硬币另一面 = 事件风险：做空近月 = 做空事件风险，恐慌真坐实（台风真减产）近月 IV 冲更高，你亏。今天 sr 台风是镜像——卖方怕的正是恐慌来源。日历价差挡方向不挡事件 spike，是"我判断恐慌会退潮"的有结构保护版裸赌

**两条路径对比：**
- 日历价差：倒挂**期间**进，收恐慌溢价退潮 = 在车上等它走
- 等修复后卖远月：倒挂**结束**进，吃远月过度回落残渣 = 等走完再上车（规则内吃不到）

**串起学习路径**：认知考核 #5 读形状背后事件（今天练）→ #6 判 IV 方向（iv_direction_pred.csv 天天练"恐慌会退潮还是坐实"）→ S2 Layer 3 拿这两条能力做日历价差。S1 禁卖方不是保守，是两条能力验证到位前，不许用钱赌"恐慌会退潮"。

为什么"收窄开始"也不能进

1. 法则① 还在生效。收窄 ≠ 倒挂结束。近月 16.3%→15.0%，只要还 > 远月，倒挂一天没消失，规则一天禁卖方。"收窄开始"这个时点在规则里根本不是进场触发——它是"还没到能卖的状态"。

2. 收窄是结果，不是拐点。收窄开始 = 近月已经跌了一段 = 顶点已过。你卖远月吃的是"IV 还没掉"的溢价——顶点时最厚，收窄开始时已经被吃一截。等你看到收窄再进，你卖的是"已经跌过的 IV"。

3. 真正的卖点在顶点（恐慌最高、远月 IV 最贵时）——那时卖远月，恐慌消退时远月过度回落，你赚的是这整段。但那需要你判断"见顶了"，这是edge——难、可证伪、要胆子，规则给不了。
