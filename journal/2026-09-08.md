- 1. · 什么是「形状贵」vs「全体贵」

全体贵 = IV 的水平高：同一标的所有行权价（call、put、ATM、两翼）都贵。例：今天 au IV-HV +6.9% 分位 93%、ru 分位 100% = 全体贵。→ 卖方整体有溢价可收，买方付贵保险。

形状贵 = IV 的形状歪了：平均下来不贵，但一侧贵到离谱。例：300ETF put 侧 IV ~90 分位、call 侧 ~30 分位、摊到 ATM 一平均 = 中位 48%。→ 贵的不是「这个期权」，是「put 这一侧」。

打个比方——level 是整条街房价都涨了；skew 是只有临河那排涨上天，别的没动。你买河对岸那套，就不算买在贵上。

两个用法别混：
- 全体贵 + 卖方 → 收 premium 有道理（au 那种），前提是贵没道理（无真实事件在窗内）
- 形状贵 + 卖方 → 别在贵的那侧裸卖（怕 skew 回归打脸 + 恐慌未消有尾部）——要收就收价差封尾
- 形状贵 + 买方 → 别买贵侧，买相对便宜侧（C 题答案的机制）

- 2. ma 倒挂为什么毙？（你的 Sinclair A 问题）

2. 卖方数学的前提是 IV 高估了（贵得没道理 → 收得到错价）。当近月贵是因为「48 天内真可能爆」→ 你卖的不是高估的期权，是给一个有日期的真实风险卖保险。

反方先给："绿了就机械开"如果变成不动脑的肌肉反射，本身也是一种风险——门是 S1 edge 的近似编码，不是完整模型，总会有门没覆盖的第一次。机械到拒绝更新门 = 僵硬，不是纪律。所以答案不是简单的是，是带三个正当例外的"是"。

按系统设计：是。四层全绿 = "开"这个字已经在门里替你判完了。 门绿的瞬间，判断环节结束，剩下的是执行（六步里的动作），不是再判一次。你在绿了之后还想"再想想该不该开"——那一次复核没有任何新信息，只有情绪。判断该由门承担，你抢回来再判，是最危险的一判。

但三个正当的不开（归 C，不算心理，不算 B）：

1. 执行层客观卡住：组合单不成交 / 盘口不可成交 / 冻结价异常——"组合单不成交不做"是你的资金安全阀，没开成 = 执行失败，不是犹豫。
2. 你发现门没编码的新东西：某层其实不绿但 scanner 没显示、或事件类型规则没覆盖——归 C，但要把漏网层补进门。这是门在进化，不是你在犹豫。
3. 六步里四层之外的硬步骤没过：持仓冲突、事件日历里某个没进 weekly 表的硬事件。

除了这三条，全绿没开 = B，来源只有一个：心理。

关键澄清：绿 ≠ 这笔会赚。 绿 = "这是一个正期望的样本，可以亏"。单笔绿交易照样可能亏——50% 止盈线和定义风险价差就是为这个存在。如果你等的是"不可能亏的绿"，那永远等不到，而"永远等不到"正是 B 最隐蔽的形态（用"质量还不够高"包装）。

所以真正的问题不是"该不该开"，是：你信不信门？ 33/20 建的东西就是这个——不是让你变成敢交易的勇敢者，是让你绿了照做时不需要勇敢。判断交给门，执行交给手，情绪没有座位。你不需要对每笔都对，你只需要对分布对——绿交易亏几笔是 edge 的成本，已定价。

最后，让"机械开"安全的那块拼图你已经有了：认知考核 #7 的三指标在量门的正确率（误杀 = 黄了但实际可交易、保守错杀 = 因黄不敢 override）。绿了照做 + 事后数门对不对——既不吃恐惧的亏，也不吃门错的亏。门信任自己是有条件的，条件就是你手里在记的数。
