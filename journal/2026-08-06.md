## 今日学到

- IV-HV 折价 = 期权相对便宜。但便宜 ≠ 有套利，便宜 = 市场认为接下来会比最近安静。

逻辑链：
- IV = 市场给未来波动定的价（forward-looking）
- HV = 过去实际跑出来的波动（backward-looking）
- 甲醇 IV-HV -18.2% = 市场说"焦煤跌 6.8% 那波过去了，接下来稳了"
- 你卖期权 = 你赌市场错了、实际波动会比 IV 大 → 赌反了，你的 edge 是负的

卖方要的是 IV > HV——卖贵了，实际波动比定价低，你赚差价。现在反过来了：期权已经便宜了，你再卖 = 别人捡便宜。

- 1. 近/远 IV 对比 vs 近/远 HV 对比有什么区别？

完全不同的东西，比的是两件事。

┌───────────┬───────────────────────────────┬─────────────────────────────────┐
│           │        近月 vs 远月 IV        │     近月 HV20 vs 远月 HV60      │
├───────────┼───────────────────────────────┼─────────────────────────────────┤
│ 看什么    │ 市场预期的时间分布            │ 已发生波动的节奏变化            │
├───────────┼───────────────────────────────┼─────────────────────────────────┤
│ 回答的问  │ "市场觉得风险在近期还是远期？ │ "最近是比之前更闹还是更安静了？ │
│ 题        │ "                             │ "                               │
├───────────┼───────────────────────────────┼─────────────────────────────────┤
│ 方向      │ forward-looking               │ backward-looking                │
├───────────┼───────────────────────────────┼─────────────────────────────────┤
│ contango  │ 远期 IV > 近期 →              │ 不适用——HV                      │
│ 含义      │ 市场说"近期稳，远期不确定"    │ 没有期限结构概念，HV20 和 HV60  │
│           │                               │ 是同一品种不同窗口              │
└───────────┴───────────────────────────────┴─────────────────────────────────┘

HV20 vs HV60 的对比只能告诉你一件事：波动率在加速还是减速。HV20 < HV60 → 最近 20 天比过去 60 天平均更安静 → 波动率在收敛。IV 近/远对比告诉你市场预期这个收敛会不会持续。

两者合在一起才有用：HV 收敛 + IV contango = 市场相信收敛会持续（适合卖方）。HV 收敛 + IV backwardation = 市场不信这波平静（警惕）。

---
2. 近月 IV 低 + 近期有事件 = 不是好的买方机会？

对，但结论比"对"更精确。

近月 IV 低意味着市场已经把已知事件定价了——或者定价为"不炸"。你买期权赌的是市场错了——要么事件比市场想象的更炸，要么有市场没预料到的新冲击。

甲醇 D-6 的情况：焦煤暴跌已经发生、已经定价。IV 在 19.8% 说明市场说"剩下 6 天没啥了"。你买 Put = 赌这 6 天里还有第二轮。这是低概率高赔率的赌注——不是不能赌，但要清楚你在赌什么。

低 IV ≠ 自动买方窗口。买方窗口 = 低 IV 且你有理由相信市场低估了未来的波动。这回到你 Scanner 里的两关一判：趋势 + IV 低 + RR 够——趋势那关就是帮你过滤"低 IV 但没方向"的情况。

---
3. 低波动 = 卖方机会 vs IV-HV 折价不卖，矛盾吗？

不矛盾。你混淆了"低"的两个不同含义。

- "波动低" = IV 的绝对值低（如甲醇 19.8%）
- "IV-HV 折价" = IV 相对于已实现波动低（IV 19.8% vs HV ~38%）

卖方赚的是 IV 和未来实际波动之间的差。关键问题不是"IV 绝对值高不高"，而是"IV 比未来实际波动高还是低"。

IV 绝对值低 + IV > HV → 可以卖（虽然赚得少，但 edge 是正的）
IV 绝对值高 + IV < HV → 不能卖（绝对值高但还不够高——市场在说"还会更炸"）

甲醇今天的 IV -18.2% 折价 = 市场已经比你更悲观了。你卖 = 你说"我觉得连 19.8% 都太高了，实际会更安静"。近月 HV20 是 ~38%，你说接下来会比 38% 的 1/3 还安静——这个赌注的 edge 在哪？

卖方做的是"卖贵了"，不是"卖绝对值高的"。

4. IV 均值回复——方向和速度

Sinclair Ch4 的核心结论（这本书我读过的部分可以帮你提炼）：

方向：向长期均值回归，但均值本身会漂移。

不是"高了就会跌、低了就会涨"那么简单。均值回复的方向取决于：
1. 当前 IV 偏离长期均值的幅度——偏离越大，回归力越强（像弹簧）
2. 均值本身是否在移动——如果体制切换了（新政策、新波动率区间），均值本身在漂移，那"回归"的目标是移动靶

速度：不是固定的。
- 极端偏离（P95+ 或 P5-）回归快——因为做市商对冲螺旋会自我加速修正
- 中等偏离（P70-P90）回归慢——没有强制力，市场可以"贵一阵子"
- 半衰期因品种而异——美股 SPX 大概 30-45 天，中国商品期权？没人算过。

对你系统的实操含义：

IV 均值回复在你的框架里是宏观方向判断，不是进场信号。你每天 iv_collector 打的五条分已经隐含了这个逻辑——分位、价差、趋势一起看，不会单看均值回复下注。
