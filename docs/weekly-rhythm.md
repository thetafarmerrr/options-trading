```
09:30 采完 → 算 Δpp → actual
   ↓
① 教练搜事实 + 写 actual_reason_coach → 落盘（回执不回显正文）
   ↓
② 用户口述 actual_reason              → 落盘
   ↓
③ 两侧同时亮出 → 判据四问逐条过用户版 → 写进当日 journal
```

| 项 | 内容 |
|---|---|
| **顺序** | **不可颠倒**——教练先写，为的是让教练版不沾用户的措辞框架（9/23 实测：教练先读了用户理由，草稿全长成「接着她的句子修」） |
| **两侧都写** | `actual_reason`（用户·主产出）· `actual_reason_coach`（教练·**参考解，不进计分**） |
| **事实核实（教练·硬项）** | 每条事件带日期 + 标「窗口内／窗口外」+ 可追溯来源。**每条都可被你核查、驳回** |
| **判据四问（过用户版）** | **A 变化性**（驱动在这 5 天里变化了吗→①升级 ②逼近结算日 ③窗内新数据；日期落窗外是特例）· **B 三段齐**（传导段不能省）· **C 可伪**（IV 反向时这句还成立吗）· **D 合法出口**（写不出因果→写「原因不明」，合规不扣分） |
| **四问不能替代核实** | 四问是**形式**检查。cf 那条「iv 高位不下」能过四问的一部分，却与数据（实为 −1.65pp 折价）矛盾——**只有事实核实能抓**。两层都要跑 |
| **不补历史** | 已有 160 行 `actual_reason_coach` 留空（9/23 用户裁定），只从 9/25 起填 |

> 反方（照 反方强制 先给）：① **对照日 +15 分钟**，这天最挤，最可能被砍的就是搜索那一环 ② **教练版有权威幻觉**——标了「参考解」容易让人停止自己判断，而这套系统的全部价值在用户产出因果 ③ **形式门槛不判质量**（同教练执行期检查那条的反方第 ③）

## Sinclair 学习方法（7/16 重构）

**旧法（已废弃）**：按章节顺序每天读 60-90 分钟，写笔记。对 INTP 无效——启动成本太高。

**新法（问题驱动）**：
1. **前置：30 分钟建地图**（一次性的）——翻全书，只扫标题+术语+图表标题。合上书能说出"偏度在哪章、期限结构在哪章"
2. **每日**：Scanner 碰到问题 → 教练压缩成一句话 → 翻书定位 → 读到答案 → 接上当天信号
3. **周六**：翻本周读过的片段，3 分钟回想——每段一句话
4. **Douglas**：读 1 段 → 写一句"今天有没有这个心理？"

> 不再有"第 5 章阅读拆分"——问题来自市场，不来自课程表。

## 影响力（每天 ≤1 条，有料就发）

### Twitter 碎片 — 每天即时发
- **素材来源**：当天扫描结论、IV 异常标注（如"甲醇 ATM IV +14% 但 call wing 折价"）、交易归因一句话
- **格式**：1-2 句中文 + 数据点。不要标题党，不要"震惊！"——数据说话
- **执行**：每天签到第 5 步→有料立刻发，不发就没了，不攒草稿。没料→过。5 分钟/条
- **硬约束**：不在交易时段发。不回复杠精。不删帖。每天 ≤1 条

### Substack/公众号 — 每月 1 篇
- **初稿**：`python3 tools/monthly_report.py` 生成骨架 → AI 扩展成文 → 你加一句话判断（"但这个月真正值得注意的是…"）
- **执行**：每月第一个周六，从当月碎片+报告提炼。2 小时/篇
- **硬约束**：AI 写初稿，你只加"数据漏了什么"那一句。不从头写

### Reddit 回帖 — 每周六 1 条
- r/options 或 r/thetagang，挑一个你做过的问题回。3-5 句英文
- **素材**：本周交易中的实际决策（"我做了 X，因为 Y"）。不讲理论

> 所有内容 = 工作副产品。不硬凑。D 门 > 涨粉。
