# 3. 额外补充解构板块（拓展学习内容）
## （1）全文行文逻辑结构拆解
1. 开场引入：自我介绍+本期主题option premium
2. 基础规则：期权报价×100合约乘数，单股价格与实际合约金额换算
3. 核心构成：权利金=内在价值+外在价值，配套数字演算案例
4. 图表分点讲解
   - 推高权利金三要素：实值深度、隐含波动率、剩余到期时间
   - 压低权利金三要素：虚值、波动率下行、临近到期
5. 交易双方逻辑对比：期权买方 VS 期权卖方（开仓、平仓、盈利条件）
6. 段落总结takeaways：复盘价值构成、波动率与时间的作用
7. 频道固定收尾：答疑渠道、点赞订阅引导

## （2）成对对比核心概念（易混考点）
1. 价值构成：内在价值（可精确计算）VS 外在价值（受时间、波动率影响）
2. 期权虚实：ITM实值（含内在价值）VS OTM虚值（无内在价值）
3. 交易双方：
   买方：开仓付费、低买高卖、亏损上限为权利金
   卖方：开仓收钱、高卖低平、潜在亏损更大
4. 时间影响：剩余时间越长→权利金越高；临近到期→时间衰减加速

## （3）文中全部计算公式
1. 合约实际总价值 = 单股期权报价 × 100
2. Extrinsic Value = Total Premium − Intrinsic Value
3. 买方盈利 = 平仓卖出权利金 − 开仓买入权利金
4. 卖方盈利 = 开仓卖出权利金 − 平仓买回权利金
5. Call实值判定：标的股价 > 行权价
6. Put实值判定：标的股价 < 行权价
