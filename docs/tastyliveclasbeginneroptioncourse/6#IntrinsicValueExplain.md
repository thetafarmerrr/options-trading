So let’s move to the next slide and go over the core takeaways for intrinsic value overall.
1. Premium = Intrinsic Value + Extrinsic Value
There are many variables that impact premium pricing, including stock price, time remaining until expiration, and volatility. But simplified, premium is always the sum of intrinsic and extrinsic value. This formula is reversible: if you know the total option price and its intrinsic value, subtract intrinsic value to solve for extrinsic value. You can rearrange the formula to calculate whichever component you’re missing.

2. In-the-money options contain both intrinsic and extrinsic value
As shown in our opening chart, extrinsic value forms a bell curve shape. All ITM options carry intrinsic value, but extrinsic value shrinks the deeper you travel into the money.

3. Out-of-the-money options only hold extrinsic value
With out-of-the-money options, there is zero intrinsic value; the contract would hold no inherent worth at expiration. For calls, ITM = strike below stock price, so OTM = strike above stock price. If a call’s strike sits higher than market price, there’s no benefit to exercising. For our 100 stock price example, a 110 strike call has no intrinsic value.

4. Being in the money does not guarantee profitability
We receive this question frequently from support tickets. Traders assume an ITM contract automatically means profit. This only holds true if you are long the option or long a spread. If you sold an option or credit spread, the contract moving ITM creates a loss. When you sell an instrument, you must buy it back to close the position. If you sell at price X and repurchase at 2X, you sustain a loss of X.

5. Call intrinsic value exists when strike < stock price
Calls grant the right to buy shares at a fixed price, so intrinsic value forms when the strike price is a discount to market price. This inherent value will be realized at expiration.

6. Put intrinsic value exists when strike > stock price
Puts grant the right to sell shares at a fixed price, so intrinsic value forms when the strike price is higher than market price. This value can be captured via exercise at expiration.

7. All in-the-money options trade above their intrinsic value
No arbitrage opportunity exists here. You will never find an ITM option trading below its intrinsic worth — if a contract holds $10 intrinsic value, it cannot be bought for $9, as that would generate risk-free profit at expiration. This permanent gap is the extrinsic value buffer. So total premium always equals intrinsic value plus extrinsic value.

## 2. 成对对比易混概念
1. Intrinsic Value（固定可计算）VS Extrinsic Value（波动，受时间/波动率影响）
2. ITM期权（内在+外在双重价值）VS OTM期权（仅存外在价值）
3. ATM（最高时间价值）VS Deep ITM（极低时间价值）
4. 期权买方（ITM利好）VS 期权卖方（ITM产生浮亏）
5. Call实值判定（Strike＜Price）VS Put实值判定（Strike＞Price）

## 3. 文中全部计算公式
1. Total Option Premium = Intrinsic Value + Extrinsic Value
2. Extrinsic Value = Total Premium − Intrinsic Value
3. Call Intrinsic Value = Stock Price − Strike Price（仅ITM时生效）
4. Put Intrinsic Value = Strike Price − Stock Price（仅ITM时生效）
5. 单合约总内在价值 = 内在点数 × 100
