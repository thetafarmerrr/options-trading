4. 卖方反向规则讲解：OTM对卖方有利、ITM产生亏损；搭配看跌期权演算案例

6. 看涨期权双向案例

   ③ 卖方偏好虚值到期，买方偏好实值到期

## （2）成对对比易混核心概念
1. ITM 实值期权 VS OTM 虚值期权
   - ITM：存在内在价值；买方到期盈利基础，卖方亏损来源
   - OTM：无内在价值；卖方全额收取权利金，买方全部亏损投入
2. 看涨Call虚实判定 VS 看跌Put虚实判定
   - Call ITM：行权价＜现价；Call OTM：行权价＞现价
   - Put ITM：行权价＞现价；Put OTM：行权价＜现价
3. 期权买方逻辑 VS 期权卖方逻辑
   - 买方：付出权利金，赌行情走出行权区间，盈利来源于内在价值
   - 卖方：收取权利金，赌行情维持虚值，盈利上限为收到的权利金
4. 账面浮亏（marked loss）VS 到期实际盈亏
   - 持仓中途可能浮亏，只要到期维持虚值，卖方最终全额盈利

## （3）文中全部计算公式&演算逻辑
1. 单合约总权利金 = 每股报价 × 100（标准期权合约乘数）
2. 内在价值（ITM期权）= 标的现价 − 看涨行权价 / 看跌行权价 − 标的现价
3. 买方到期盈利 = 内在价值总金额 − 买入付出总权利金
4. 卖方到期盈利 = 卖出收到总权利金（期权维持OTM归零）
5. 买方最大亏损 = 开仓支付全部权利金（期权OTM到期）
