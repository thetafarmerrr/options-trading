# 期权策略赚钱来源（全五层）

> 开仓前先问：这笔赚的什么钱？
> L 标记 = MASTER_PLAN 什么时候开始做。

---

## 🟢 L1 · 卖方价差
> 只卖不做别的。

| 策略 | 赚什么 | 亏什么 |
|------|--------|--------|
| 卖 Put 信用价差 | Theta + Vega↓ | 期货跌向卖腿 |
| 卖 Call 信用价差 | Theta + Vega↓ | 期货涨向卖腿 |

## 🟡 L2 · IV 驱动方向
> IV 高→卖，IV 低→买。

| 策略 | 赚什么 | 亏什么 |
|------|--------|--------|
| 铁鹰 | 双倍 Theta + Vega↓ | 期货突破边界 |
| 卖跨式 | Theta + Vega↓ | 暴涨暴跌，无限亏损 |
| 卖宽跨式 | Theta + Vega↓（OTM 版） | 同上，需更大波动 |
| 买跨式 | Gamma↑ + Vega↑ | 期货不动→Theta 扣血 |
| 买宽跨式 | Gamma↑ + Vega↑（成本更低） | 需更大跳空 |
| 牛市看涨价差 | Delta↑ + Theta | 期货跌 |
| 熊市看跌价差 | Delta↓ + Theta | 期货涨 |

## 🟠 L3 · 曲面与结构
> 偏度、期限结构、IV 曲面。

| 策略 | 赚什么 | 亏什么 |
|------|--------|--------|
| 日历价差 | 近月 Theta > 远月 Theta + 曲面变化 | IV 期限结构反向 |
| 对角价差 | 日历+垂直：Theta 差 + 曲面 + Delta | 双重风险 |
| 蝶式 | Theta（三腿窄区间） | 期货突破窄区间 |
| 比率价差 | 偏度回归（卖多买少） | 暴跌加速 |
| 反向比率价差 | 偏度爆发（买多卖少） | 市场不动 |
| 虚值倒挂 | 定价错误回归 | 不回归/流动性差 |

## 🔵 L4 · 跨市场/跨资产
> 期货对冲、跨品种、金融期权。

| 策略 | 赚什么 | 亏什么 |
|------|--------|--------|
| 持保看涨 | 持有期货 + 卖 Call，赚 Theta | 期货暴跌超权利金 |
| 保护性看跌 | 持有期货 + 买 Put 保险 | 保费 > 利润 |
| 领子期权 | Covered Call + Protective Put，零成本锁区间 | 突破区间 |
| 跨品种价差 | 两品种定价偏差回归 | 基本面永久变化 |
| 跨市场套利 | 跨交易所定价差 | 汇率/政策/管制 |
| Delta 中性对冲 | 期权+期货对冲 Delta，赚 Gamma 剥头皮 + Vega 曲面 | 对冲成本 + 跳空 |

## 🔴 L5 · 做市与流动性
> 双边报价、库存管理、原创研究。

| 策略 | 赚什么 | 亏什么 |
|------|--------|--------|
| 双边报价 | bid/ask 价差 | 库存方向风险 |
| 转换套利 | 合成空头 vs 期货定价偏差 | 利率变化 |
| 反转套利 | 合成多头 vs 期货定价偏差 | 同上 |
| 盒式价差 | Put-Call Parity 偏离（无风险） | 手续费吃掉薄利 |
| 波动率互换 | 已实现 vs 约定波动率差 | 单边暴涨暴跌 |
| 动态 Delta 对冲 | Gamma 剥头皮 | 跳空+交易成本 |
