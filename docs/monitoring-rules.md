# 持仓监控与进场规则（Layer 1 · 卖方信用价差专用）

> 从 5 笔亏损中提炼。每条对应一个真实亏过的场景。
> 买方规则、曲面策略、跨式等 → 到对应 Layer 再建独立文档。

---

## 一、持仓监控：三档体系

| 档位 | OTM 距离 | 触发条件 | 行动 |
|------|---------|---------|------|
| 🟢 正常 | >3% | 任何情况 | 不动，每天看一眼 |
| 🟡 警戒 | 2-3% | 期货在向卖腿方向移动 + 到期 < 30 天 | 评估平仓成本。亏 < 30% 最大亏损 → 可平 |
| 🔴 高危 | 1-2% | 期货向卖腿移动 + 任何到期日 | 平。除非 > 45 天且期货已止跌反弹 |
| ⛔ 撤离 | <1% | 无条件 | 立刻平。不等。不犹豫 |

### 额外触发

- 两腿都变实值 → 亏损已封顶 → 平仓释放保证金
- 事件突然降临（如贸易战新闻） → 立刻平
- 其他情况 → 不动。等到期

## 二、开盘环境定性（Sinclair 第 3 章 · 60 秒）

> 每天开盘前扫一遍。不是预测方向，是给当前市场状态定性。
> 5 条中 ≥ 3 条不利 → 今天不开新仓，甚至减仓。≥ 3 条有利 → 积极寻找卖方机会。

| # | 典型事实 | 检查内容 | 🟢 有利 | 🔴 不利 |
|:--:|------|------|------|------|
| 1 | 波动率聚集 | 过去 5 天 HV 涨还是跌？ | HV 在跌 → 波动退潮，卖腿安全垫变厚 | HV 在涨 → 波动聚集，被击穿概率上升 |
| 2 | 高波动环境持续，但每天不保证 | 当前在低波动期还是高波动期？ | 低波动期 → 常态，放心收租 | 高波动期 → 不加仓。等 HV 回落确认再动作。昨大 K ≠ 今天必大 K，但环境没变 |
| 3 | 跌时 IV 涨得比涨时快（杠杆效应） | 近期跌时 IV 跳了多少 vs 涨时？ | IV 对下跌不敏感 → 市场不恐慌，卖 Put 安全 | 跌 1% IV 跳 2% → 价格跌+IV涨 = Put 双倍跳。减仓信号 |
| 4 | 成交量与波动率正相关 | 今日量放大还是萎缩？ | 缩量+IV跌 → 卖 Put 最佳时机 | 放量+IV涨 → 极高谨慎，恐慌交易中 |
| 5 | 波动率均值回归 | IV 在历史什么位置？还在加速涨还是已企稳？ | IV 高位**企稳/开始回落** → 黄金窗口：权利金厚+回归方向对卖方有利 | IV **加速涨**中 → 别抢跑。加速段卖= Vega还在亏+标的可能还在砸=双杀。等加速停止再进场 |

```
[1] HV 趋势：涨 ⬆ / 跌 ⬇ / 平 ➡
[2] 波动环境：高 / 低  
[3] 杠杆效应：跌时IV___ 涨时IV___ → 不对称？
[4] 成交量：正常 / 异常放大 / 萎缩
[5] IV 分位：___% + 加速 ⬆ / 企稳 ➡ / 回落 ⬇

→ 有利 _/5  不利 _/5  → 今天：开仓 / 持有不动 / 减仓
```

### HV 期限结构补充（卖方信用价差专用）

> HV₂₀ 和 HV₆₀ 来自 `iv_collector` 输出。⚡/😴 标记自动显示。

| HV₂₀ − HV₆₀ | 含义 | 开仓 |
|------|------|------|
| > +3% | 近期剧烈波动 ⚡ | **不开新仓**。波动聚集，卖方逆风 |
| 0 ~ +3% | 近期偏活跃 | 开，仓位减半 |
| −3% ~ 0 | 稳态 | 正常执行 |
| < −3% | 近期异常安静 😴 | 正常执行，但检查 IV 绝对值（<30% 分位 → 权利金薄，也不做） |

> 买方逻辑相反：HV₂₀ >> HV₆₀ 是波动聚集期，对 Vega 正敞口有利。

### 量价真伪验证（卖方信用价差专用）

> 成交量是波动信号的"验真器"。`iv_collector` 第 5 条自动输出。

| IV 分位 | 放量（>均量 1.2x） | 缩量（<均量 0.8x） |
|------|------|------|
| **偏高 >70%** | 🔴 贵是"真贵"——分歧真实，不追卖 | 🟢 贵是"虚高"——无人参与，可卖 |
| **偏低 <30%** | 无论量 → 不卖（权利金太薄） | 无论量 → 不卖 |
| **正常 30-70%** | 观察，谨慎 | 正常执行 |

### 信号冲突处理

> 当第 4 条和第 5 条信号矛盾时，人工裁决。

| 场景 | 冲突 | 裁决 |
|------|------|------|
| 缩量虚高 + HV₂₀−HV₆₀ > 3% | 量说虚的可卖，HV 差说真在扩张 | ① 仓位减半 ② 设 2 天时间止损（2 天内缩量未缓解 → 平仓） |
| 放量真贵 + HV 收缩 | 量说真的别卖，HV 差说环境安全 | 等一天。量先退潮 → 可进；量持续放大 → 弃 |

## 三、进场决策：六步检查

```
1. Scanner 出信用价差信号
      ↓
2. OTM > 2%？ → 否 → 不做
      ↓ 是
3. 同花顺确认期货现价 > 推断价
      ↓
4. 最近 5 天期货有没有跌破过卖腿？
      ↓ 有 → 等企稳（站稳卖腿上方 3 天+）
      ↓ 无
5. IV 有没有暴涨？（价差突然跳 5%+ 或 ATM bid 跳 20%+）
      ↓ 有 → 等回落
      ↓ 无
6. 赚什么钱？说出来再下单
   - 卖信用价差 → Theta + Vega↓
   - 买跨式 → Gamma↑ + Vega↑
   - 虚值倒挂 → 定价错误回归
   （说不出来 → 不做）
      ↓ 清楚
7. 做
```

### 额外检查

- D-0/D-1 高影响事件 → 不做卖方
- 同一品种已有持仓 → 不加同款
- 盈亏比 < 0.25 → 不做

## 四、离场决策：六步检查

> 每天检查持仓时依次走一遍。任意一步触发 → 平。不讨论。

### 开仓即写死止盈价（对抗盯盘纠结）

> 信用价差开仓时，立刻算出止盈的**绝对金额**并写进日志。盘中只比对这个数，不临时决定。

- 止盈 ¥ = 收的 credit × 50%
- 例：credit ¥60 → 止盈线 ¥30。浮盈到 ¥30 就平，不看还能不能多赚。
- **¥30 和 ¥40 不是选择题。** 线在 50%（¥30）。等到 67%（¥40）才"立马平"= 已经贪了一轮。
- 峰值抓不住，别为峰值复盘。有规则的执行 > 事后懊悔没卖在最高点。
- Te 先于 Ti：数字事先定死（Te），盘中只执行（不给 Ti-Ne 相机行事的空间）。

```
1. 浮盈 ≥ 最大利润 × 50%？
      ↓ 是 → 平。后半段 Theta 慢，落袋释放保证金
      ↓ 否
2. 期货触及买腿行权价？
      ↓ 是 → 平。这是开仓前定的硬线
      ↓ 否
3. 剩余 ≤ 2 个交易日？
      ↓ 是 → 平。末日 Gamma + 指派风险，不赚最后一个硬币
      ↓ 否
4. 两腿都实值？
      ↓ 是 → 平。亏损已封顶，持仓无意义
      ↓ 否
5. OTM < 1% + 期货向卖腿方向移动？
      ↓ 是 → 平。撤离区，下一站就是止损线
      ↓ 否
6. D-0/D-1 高影响事件？
      ↓ 是 → 平。睡醒 IV 跳 50% 不值得
      ↓ 否
  持有。明天再走一遍。
```

### 平仓顺序（执行细节）

- **先买平卖腿，后卖平买腿**（和开仓反过来，避免短暂裸卖）
- 深实值平仓 → 两条腿同时挂，不分步
- 期货剧烈波动时 → 等稳定后同时平，不抢单

### 离场优先级

| 优先级 | 触发条件 | 行动速度 |
|--------|---------|---------|
| 🔴 立即 | 止损线被击穿、D-0 高影响事件 | 开盘即平，不挂限价等成交 |
| 🟡 当日 | 止盈触发、两腿实值 | 当天找时机平，不等明天 |
| 🟢 关注 | 接近止盈（浮盈 40%+）、OTM 靠近 1% | 明天再看，但心理准备好 |

### 进场六步 vs 离场六步

```
进场                              离场
──────────────────────────        ──────────────────────────
1. Scanner 出信号                  1. 浮盈 ≥ 50%？
2. OTM > 2%？                     2. 期货触及买腿？
3. 同花顺确认期货价                 3. 剩 ≤ 2 天？
4. 5 天内有跌破卖腿？               4. 两腿都实值？
5. IV 暴涨？                      5. OTM < 1% + 方向不利？
6. 赚什么钱？说出来                  6. 明天有事件？
```

## 六、禁止清单

- 不分腿下单 → 用文华财经组合单。不成交不做
- 不在事件前做卖方
- 不裸卖。任何情况下。
- 不在近值（OTM < 2%）进场
- 不因为"账户闲着"而强行下单
- ITM 信用价差不做（L1）
- 浮亏/浮盈不是平仓理由。按监控规则，不按感觉

## 七、手续费与真实成本

> 真实盈亏 = 毛利 − 手续费 − 滑点。中间价的数学永远比实际乐观。算盈亏必须扣成本。

### 各品种期权手续费（交易所标准，全国统一）

| 品种 | 交易所 | 交易手续费/手 | 行权/履约/手 |
|------|--------|--------------|-------------|
| 菜粕 RM | 郑商所 | **0.8 元** | 0.8 元 |
| 玉米 c | 大商所 | **0.6 元** | 0.6 元 |
| 甲醇 MA | 郑商所 | **0.5 元** | 0.5 元 |
| PTA TA | 郑商所 | **0.5 元** | 0.5 元 |

- **券商加收**：默认 2-5 元/手（贵），可协商到"交易所 + 0.01~0.5 元"。实际成本 = 交易所 + 加收，以自己结算单为准
- **申报费**：只对高频报撤单（>4000 笔/日）收取，普通交易 0
- **行权费**：持有到行权才收。**平仓离场不产生行权费 + 免指派风险**——离场六步"剩≤2天平仓"的隐藏收益

### 信用价差成本速算

```
来回成本 = 交易所费/手 × 腿数 × 2（开+平）  [交易所底价]
```

单腿价差（2 条腿）交易所底价来回：

| 品种 | 底价来回（2腿×开平） |
|------|---------------------|
| 菜粕 RM | 0.8 × 4 = ¥3.2 |
| 玉米 c | 0.6 × 4 = ¥2.4 |
| 甲醇 MA | 0.5 × 4 = ¥2.0 |
| PTA TA | 0.5 × 4 = ¥2.0 |

加券商佣金后大致翻倍。跨式等按实际腿数算。

### 为什么成本决定策略

- 对 ¥60 credit 的小价差，来回成本 ~¥3-8 = **最大盈利的 5-13%**
- **不能靠捡小利差交易**——费用吃光。早平/小仓时费用占比更高
- 案例：菜粕 2609 毛利 +¥10，扣费 ~¥5 → 净利 ~¥5。费用占毛利 30-80%。少赚的 ¥20（裸空拖延）让费用占比从 17% 飙到 50%

---

> 这些规则不是写出来的。是菜粕 ¥140、玉米跨式 ¥80、PTA ¥203、玉米 ¥20 四笔亏损买出来的。
> 「开仓即写死止盈价」是菜粕 2609 价差（credit ¥60）买的教训——浮盈到过 ¥30（50% 线）没平，跌回 ¥25 才纠结「30 还是 40」。规则线在 50%，事先写死就不用盘中纠结。
