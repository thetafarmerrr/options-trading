# 持仓监控与进场规则

> 从 5 笔亏损中提炼。每条对应一个真实亏过的场景。

---

## 一、持仓监控：三档体系

| 档位 | OTM 距离 | 触发条件 | 行动 |
|------|---------|---------|------|
| 🟢 正常 | >3% | 任何情况 | 不动，每天看一眼 |
| 🟡 警戒 | 2-3% | 期货在向卖腿方向移动 + 到期 < 30 天 | 评估平仓成本。亏 < 30% 最大亏损 → 可平 |
| 🔴 高危 | 1-2% | 期货向卖腿移动 + 任何到期日 | 平。除非 > 45 天且期货已止跌反弹 |
| ⛔ 撤离 | <1% | 无条件 | 立刻平。不等。不犹豫 |

### 额外触发

- 两腿都变实值 → 亏损已封顶 → 平仓释放保证金
- 事件突然降临（如贸易战新闻） → 立刻平
- 其他情况 → 不动。等到期

## 二、进场决策：六步检查

```
1. Scanner 出信用价差信号
      ↓
2. OTM > 2%？ → 否 → 不做
      ↓ 是
3. 同花顺确认期货现价 > 推断价
      ↓
4. 最近 5 天期货有没有跌破过卖腿？
      ↓ 有 → 等企稳（站稳卖腿上方 3 天+）
      ↓ 无
5. IV 有没有暴涨？（价差突然跳 5%+ 或 ATM bid 跳 20%+）
      ↓ 有 → 等回落
      ↓ 无
6. 赚什么钱？说出来再下单
   - 卖信用价差 → Theta + Vega↓
   - 买跨式 → Gamma↑ + Vega↑
   - 虚值倒挂 → 定价错误回归
   （说不出来 → 不做）
      ↓ 清楚
7. 做
```

### 额外检查

- D-0/D-1 高影响事件 → 不做卖方
- 同一品种已有持仓 → 不加同款
- 盈亏比 < 0.25 → 不做

## 三、离场决策：六步检查

> 每天检查持仓时依次走一遍。任意一步触发 → 平。不讨论。

```
1. 浮盈 ≥ 最大利润 × 50%？
      ↓ 是 → 平。后半段 Theta 慢，落袋释放保证金
      ↓ 否
2. 期货触及买腿行权价？
      ↓ 是 → 平。这是开仓前定的硬线
      ↓ 否
3. 剩余 ≤ 2 个交易日？
      ↓ 是 → 平。末日 Gamma + 指派风险，不赚最后一个硬币
      ↓ 否
4. 两腿都实值？
      ↓ 是 → 平。亏损已封顶，持仓无意义
      ↓ 否
5. OTM < 1% + 期货向卖腿方向移动？
      ↓ 是 → 平。撤离区，下一站就是止损线
      ↓ 否
6. D-0/D-1 高影响事件？
      ↓ 是 → 平。睡醒 IV 跳 50% 不值得
      ↓ 否
  持有。明天再走一遍。
```

### 平仓顺序（执行细节）

- **先买平卖腿，后卖平买腿**（和开仓反过来，避免短暂裸卖）
- 深实值平仓 → 两条腿同时挂，不分步
- 期货剧烈波动时 → 等稳定后同时平，不抢单

### 离场优先级

| 优先级 | 触发条件 | 行动速度 |
|--------|---------|---------|
| 🔴 立即 | 止损线被击穿、D-0 高影响事件 | 开盘即平，不挂限价等成交 |
| 🟡 当日 | 止盈触发、两腿实值 | 当天找时机平，不等明天 |
| 🟢 关注 | 接近止盈（浮盈 40%+）、OTM 靠近 1% | 明天再看，但心理准备好 |

### 进场六步 vs 离场六步

```
进场                              离场
──────────────────────────        ──────────────────────────
1. Scanner 出信号                  1. 浮盈 ≥ 50%？
2. OTM > 2%？                     2. 期货触及买腿？
3. 同花顺确认期货价                 3. 剩 ≤ 2 天？
4. 5 天内有跌破卖腿？               4. 两腿都实值？
5. IV 暴涨？                      5. OTM < 1% + 方向不利？
6. 赚什么钱？说出来                  6. 明天有事件？
```

## 四、事件日历规则

| 事件距离 | 信用价差卖方 | 买方跨式 |
|---------|------------|---------|
| D-0 到 D-1 | 不做 | 评估意外程度+价差成本 |
| D-2 到 D-7 | 可以，注意 ⚠️ 标记 | 提前布局 |
| D-7+ | 正常 | — |

## 五、禁止清单

- 不分腿下单 → 用文华财经组合单。不成交不做
- 不在事件前做卖方
- 不裸卖。任何情况下。
- 不在近值（OTM < 2%）进场
- 不因为"账户闲着"而强行下单
- ITM 信用价差不做（L1）
- 浮亏/浮盈不是平仓理由。按监控规则，不按感觉
