# 持仓监控与进场规则

> 从 5 笔亏损中提炼。每条对应一个真实亏过的场景。

---

## 一、持仓监控：三档体系

| 档位 | OTM 距离 | 触发条件 | 行动 |
|------|---------|---------|------|
| 🟢 正常 | >3% | 任何情况 | 不动，每天看一眼 |
| 🟡 警戒 | 2-3% | 期货在向卖腿方向移动 + 到期 < 30 天 | 评估平仓成本。亏 < 30% 最大亏损 → 可平 |
| 🔴 高危 | 1-2% | 期货向卖腿移动 + 任何到期日 | 平。除非 > 45 天且期货已止跌反弹 |
| ⛔ 撤离 | <1% | 无条件 | 立刻平。不等。不犹豫 |

### 额外触发

- 两腿都变实值 → 亏损已封顶 → 平仓释放保证金
- 事件突然降临（如贸易战新闻） → 立刻平
- 其他情况 → 不动。等到期

## 二、进场决策：五步检查

```
1. Scanner 出信用价差信号
      ↓
2. OTM > 2%？ → 否 → 不做
      ↓ 是
3. 同花顺确认期货现价 > 推断价
      ↓
4. 最近 5 天期货有没有跌破过卖腿？
      ↓ 有 → 等企稳（站稳卖腿上方 3 天+）
      ↓ 无
5. IV 有没有暴涨？（价差突然跳 5%+ 或 ATM bid 跳 20%+）
      ↓ 有 → 等回落
      ↓ 无
6. 做
```

### 额外检查

- D-0/D-1 高影响事件 → 不做卖方
- 同一品种已有持仓 → 不加同款
- 盈亏比 < 0.25 → 不做

---

## 三、平仓规则

### 主动平仓（到期前 < 5 天）

- OTM < 2% → 不计较最后 Theta，平仓离场
- 浮盈达最大利润 50-70% → 可提前平仓锁利

### 被动平仓（到期日）

- 到期前一天或当天下午 → 主动平（避免指派风险）
- 深实值平仓 → 两条腿同时挂，不分步。期货反弹时等稳定后同时平

### 平仓顺序

- 开盘：先买腿，后卖腿（避免裸卖）
- 平仓：先买平卖腿，后卖平买腿（和开仓反过来）

---

## 四、事件日历规则

| 事件距离 | 信用价差卖方 | 买方跨式 |
|---------|------------|---------|
| D-0 到 D-1 | 不做 | 评估意外程度+价差成本 |
| D-2 到 D-7 | 可以，注意 ⚠️ 标记 | 提前布局 |
| D-7+ | 正常 | — |

---

## 五、禁止清单

- 不分腿下单 → 用文华财经组合单。不成交不做
- 不在事件前做卖方
- 不裸卖。任何情况下。
- 不在近值（OTM < 2%）进场
- 不因为"账户闲着"而强行下单
- ITM 信用价差不做（L1）
- 浮亏/浮盈不是平仓理由。按监控规则，不按感觉
