## 一、持仓监控：三档体系

| 档位 | OTM 距离 | 触发条件 | 行动 |
|------|---------|---------|------|
| 🟢 正常 | >3% | 任何情况 | 不动，每天看一眼 |
| 🟡 警戒 | 2-3% | 期货在向卖腿方向移动 + 到期 < 30 天 | 评估平仓成本。亏 < 30% 最大亏损 → 可平 |
| 🔴 高危 | 1-2% | 期货向卖腿移动 + 任何到期日 | 平。除非 > 45 天且期货已止跌反弹 |
| ⛔ 撤离 | <1% | 无条件 | 立刻平。不等。不犹豫 |

### 额外触发

- 两腿都变实值 → 亏损已封顶 → 平仓释放保证金
- 事件突然降临（如贸易战新闻） → 立刻平
- 其他情况 → 不动。等到期

## 二、开盘环境定性（Sinclair 第 3 章 · 60 秒）

> 每天开盘前扫一遍。不是预测方向，是给当前市场状态定性。
> 5 条中 ≥ 3 条不利 → 今天不开新仓，甚至减仓。≥ 3 条有利 → 积极寻找卖方机会。

| # | 典型事实 | 检查内容 | 🟢 有利 | 🔴 不利 |
|:--:|------|------|------|------|
| 1 | 波动率聚集 | 过去 5 天 HV 涨还是跌？ | HV 在跌 → 波动退潮，卖腿安全垫变厚 | HV 在涨 → 波动聚集，被击穿概率上升 |
| 2 | 高波动环境持续，但每天不保证 | 当前在低波动期还是高波动期？ | 低波动期 → 常态，放心收租 | 高波动期 → 不加仓。等 HV 回落确认再动作。昨大 K ≠ 今天必大 K，但环境没变 |
| 3 | 跌时 IV 涨得比涨时快（杠杆效应） | 近期跌时 IV 跳了多少 vs 涨时？ | IV 对下跌不敏感 → 市场不恐慌，卖 Put 安全 | 跌 1% IV 跳 2% → 价格跌+IV涨 = Put 双倍跳。减仓信号 |
| 4 | 成交量与波动率正相关 | 今日量放大还是萎缩？ | 缩量+IV跌 → 卖 Put 最佳时机 | 放量+IV涨 → 极高谨慎，恐慌交易中 |
| 5 | 波动率均值回归 | IV 在历史什么位置？还在加速涨还是已企稳？ | IV 高位**企稳/开始回落** → 黄金窗口：权利金厚+回归方向对卖方有利 | IV **加速涨**中 → 别抢跑。加速段卖= Vega还在亏+标的可能还在砸=双杀。等加速停止再进场 |

```
[1] HV 趋势：涨 ⬆ / 跌 ⬇ / 平 ➡
[2] 波动环境：高 / 低  
[3] 杠杆效应：跌时IV___ 涨时IV___ → 不对称？
[4] 成交量：正常 / 异常放大 / 萎缩
[5] IV 分位：___% + 加速 ⬆ / 企稳 ➡ / 回落 ⬇

→ 有利 _/5  不利 _/5  → 今天：开仓 / 持有不动 / 减仓
```

### HV 期限结构补充（卖方信用价差专用）

> HV₂₀ 和 HV₆₀ 来自 `iv_collector` 输出。⚡/😴 标记自动显示。

| HV₂₀ − HV₆₀ | 含义 | 开仓 |
|------|------|------|
| > +3% | 近期剧烈波动 ⚡ | **不开新仓**。波动聚集，卖方逆风 |
| 0 ~ +3% | 近期偏活跃 | 开，仓位减半 |
| −3% ~ 0 | 稳态 | 正常执行 |
| < −3% | 近期异常安静 😴 | 正常执行，但检查 IV 绝对值（<30% 分位 → 权利金薄，也不做） |

> 买方逻辑相反：HV₂₀ >> HV₆₀ 是波动聚集期，对 Vega 正敞口有利。

### 量价真伪验证（卖方信用价差专用）

> 成交量是波动信号的"验真器"。`iv_collector` 第 5 条自动输出。

| IV 分位 | 放量（>均量 1.2x） | 缩量（<均量 0.8x） |
|------|------|------|
| **偏高 >70%** | 🔴 贵是"真贵"——分歧真实，不追卖 | 🟢 贵是"虚高"——无人参与，可卖 |
| **偏低 <30%** | 无论量 → 不卖（权利金太薄） | 无论量 → 不卖 |
| **正常 30-70%** | 观察，谨慎 | 正常执行 |

### 信号冲突处理

> 当第 4 条和第 5 条信号矛盾时，人工裁决。

| 场景 | 冲突 | 裁决 |
|------|------|------|
| 缩量虚高 + HV₂₀−HV₆₀ > 3% | 量说虚的可卖，HV 差说真在扩张 | ① 仓位减半 ② 设 2 天时间止损（2 天内缩量未缓解 → 平仓） |
| 放量真贵 + HV 收缩 | 量说真的别卖，HV 差说环境安全 | 等一天。量先退潮 → 可进；量持续放大 → 弃 |

## 三、进场决策：六步检查

```
1. Scanner 出信用价差信号

      ↓ 是
3. 同花顺确认期货现价 > 推断价
      ↓

      ↓ 无
5. IV 有没有暴涨？（价差突然跳 5%+ 或 ATM bid 跳 20%+）
      ↓ 有 → 等回落
      ↓ 无
6. 赚什么钱？说出来再下单
   - 卖信用价差 → Theta + Vega↓

   （说不出来 → 不做）
      ↓ 清楚
7. 做
```

## 四、离场决策：六步检查

> 每天检查持仓时依次走一遍。任意一步触发 → 平。不讨论。

### 开仓即写死止盈价（对抗盯盘纠结）

> 信用价差开仓时，立刻算出止盈的**绝对金额**并写进日志。盘中只比对这个数，不临时决定。

- 止盈 ¥ = 收的 credit × 50%
- 例：credit ¥60 → 止盈线 ¥30。浮盈到 ¥30 就平，不看还能不能多赚。
- **¥30 和 ¥40 不是选择题。** 线在 50%（¥30）。等到 67%（¥40）才"立马平"= 已经贪了一轮。
- 峰值抓不住，别为峰值复盘。有规则的执行 > 事后懊悔没卖在最高点。
- Te 先于 Ti：数字事先定死（Te），盘中只执行（不给 Ti-Ne 相机行事的空间）。

```
1. 浮盈 ≥ 最大利润 × 50%？
      ↓ 是 → 平。后半段 Theta 慢，落袋释放保证金
      ↓ 否
2. 期货触及买腿行权价？
      ↓ 是 → 平。这是开仓前定的硬线
      ↓ 否
3. 剩余 ≤ 2 个交易日？
      ↓ 是 → 平。末日 Gamma + 指派风险，不赚最后一个硬币
      ↓ 否
4. 两腿都实值？
      ↓ 是 → 平。亏损已封顶，持仓无意义
      ↓ 否
5. OTM < 1% + 期货向卖腿方向移动？
      ↓ 是 → 平。撤离区，下一站就是止损线
      ↓ 否
6. D-0/D-1 高影响事件？
      ↓ 是 → 平。睡醒 IV 跳 50% 不值得
      ↓ 否
  持有。明天再走一遍。
```

### 平仓顺序（执行细节）

- **先买平卖腿，后卖平买腿**（和开仓反过来，避免短暂裸卖）
- 深实值平仓 → 两条腿同时挂，不分步
- 期货剧烈波动时 → 等稳定后同时平，不抢单

### 离场优先级

| 优先级 | 触发条件 | 行动速度 |
|--------|---------|---------|
| 🔴 立即 | 止损线被击穿、D-0 高影响事件 | 开盘即平，不挂限价等成交 |
| 🟡 当日 | 止盈触发、两腿实值 | 当天找时机平，不等明天 |
| 🟢 关注 | 接近止盈（浮盈 40%+）、OTM 靠近 1% | 明天再看，但心理准备好 |

### 进场六步 vs 离场六步

```
进场                              离场
──────────────────────────        ──────────────────────────
1. Scanner 出信号                  1. 浮盈 ≥ 50%？
2. OTM > 2%？                     2. 期货触及买腿？
3. 同花顺确认期货价                 3. 剩 ≤ 2 天？
4. 5 天内有跌破卖腿？               4. 两腿都实值？
5. IV 暴涨？                      5. OTM < 1% + 方向不利？
6. 赚什么钱？说出来                  6. 明天有事件？
```

## 七、手续费与真实成本

> 真实盈亏 = 毛利 − 手续费 − 滑点。中间价的数学永远比实际乐观。算盈亏必须扣成本。

### 各品种期权手续费（交易所标准，全国统一）

| 品种 | 交易所 | 交易手续费/手 | 行权/履约/手 |
|------|--------|--------------|-------------|
| 菜粕 RM | 郑商所 | **0.8 元** | 0.8 元 |
| 玉米 c | 大商所 | **0.6 元** | 0.6 元 |
| 甲醇 MA | 郑商所 | **0.5 元** | 0.5 元 |
| PTA TA | 郑商所 | **0.5 元** | 0.5 元 |

- **券商加收**：默认 2-5 元/手（贵），可协商到"交易所 + 0.01~0.5 元"。实际成本 = 交易所 + 加收，以自己结算单为准
- **申报费**：只对高频报撤单（>4000 笔/日）收取，普通交易 0
- **行权费**：持有到行权才收。**平仓离场不产生行权费 + 免指派风险**——离场六步"剩≤2天平仓"的隐藏收益

### 信用价差成本速算

```
来回成本 = 交易所费/手 × 腿数 × 2（开+平）  [交易所底价]
```

单腿价差（2 条腿）交易所底价来回：

| 品种 | 底价来回（2腿×开平） |
|------|---------------------|
| 菜粕 RM | 0.8 × 4 = ¥3.2 |
| 玉米 c | 0.6 × 4 = ¥2.4 |
| 甲醇 MA | 0.5 × 4 = ¥2.0 |
| PTA TA | 0.5 × 4 = ¥2.0 |

加券商佣金后大致翻倍。跨式等按实际腿数算。

### 为什么成本决定策略

- 对 ¥60 credit 的小价差，来回成本 ~¥3-8 = **最大盈利的 5-13%**
- **不能靠捡小利差交易**——费用吃光。早平/小仓时费用占比更高
- 案例：菜粕 2609 毛利 +¥10，扣费 ~¥5 → 净利 ~¥5。费用占毛利 30-80%。少赚的 ¥20（裸空拖延）让费用占比从 17% 飙到 50%

---

> 这些规则不是写出来的。是菜粕 ¥140、玉米跨式 ¥80、PTA ¥203、玉米 ¥20 四笔亏损买出来的。
> 「开仓即写死止盈价」是菜粕 2609 价差（credit ¥60）买的教训——浮盈到过 ¥30（50% 线）没平，跌回 ¥25 才纠结「30 还是 40」。规则线在 50%，事先写死就不用盘中纠结。

# 卖 Call 信用价差（Bear Call Spread）

> ⚠️ 与卖 Put 独立。两套规则结构对称，但方向相反。执行前先确认你在跑哪一套。
> 卖 Call = 赌期货不涨过卖腿。收权利金，等 Theta + Vega↓。

---

## C-一、持仓监控：三档体系（卖 Call 专用）

| 档位 | OTM 距离 | 触发条件 | 行动 |
|------|---------|---------|------|
| 🟢 正常 | >3% | 任何情况 | 不动，每天看一眼 |
| 🟡 警戒 | 2-3% | 期货在**上涨** + 到期 < 30 天 | 评估平仓成本。亏 < 30% 最大亏损 → 可平 |
| 🔴 高危 | 1-2% | 期货**上涨** + 任何到期日 | 平。除非 > 45 天且期货已止涨回落 |
| ⛔ 撤离 | <1% | 无条件 | 立刻平。不等。不犹豫 |

### C-OTM 公式

```
卖 Put OTM = (期货 − 卖腿) / 期货    ← 期货在卖腿上方是安全的
卖 Call OTM = (卖腿 − 期货) / 期货   ← 期货在卖腿下方是安全的
```

### 额外触发（卖 Call 版）

- 两腿都变实值 → 亏损已封顶 → 平仓释放保证金
- 事件突然降临（如贸易战缓和、供给恢复）→ 立刻平
- 期货涨破卖腿 + 还在涨 → 不等，平

---

## C-二、开盘环境定性（卖 Call 专用）

> 每天开盘前扫。5 条中 ≥ 3 条不利 → 不开新仓。

| # | 典型事实 | 检查内容 | 🟢 有利（卖 Call） | 🔴 不利（卖 Call） |
|:--:|------|------|------|------|
| 1 | 波动率聚集 | 过去 5 天 HV 涨还是跌？ | HV 在跌 → 安全垫变厚 | HV 在涨 → 波动聚集，被涨穿概率上升 |
| 2 | 高波动环境持续 | 低波动期还是高波动期？ | 低波动期 → 放心收租 | 高波动期 → 不加仓 |
| 3 | 杠杆效应（涨时 IV） | 近期**涨**时 IV 跳了多少 vs 跌时？ | IV 对上涨不敏感 → 市场不恐高，卖 Call 安全 | 涨 1% IV 跳 1.5%+ → 价格涨+IV涨 = Call 双倍跳。减仓 |
| 4 | 成交量与波动率正相关 | 量放大还是萎缩？ | 缩量+IV跌 → 最佳时机 | 放量+IV涨 → 极高谨慎 |
| 5 | 波动率均值回归 | IV 分位 + 方向 | IV 高位企稳/回落 → 黄金窗口 | IV 加速涨 → 别抢跑 |

```
[1] HV 趋势：涨 ⬆ / 跌 ⬇ / 平 ➡
[2] 波动环境：高 / 低  
[3] 杠杆效应：涨时IV___ 跌时IV___ → 涨时不对称？
[4] 成交量：正常 / 异常放大 / 萎缩
[5] IV 分位：___% + 加速 ⬆ / 企稳 ➡ / 回落 ⬇

→ 有利 _/5  不利 _/5  → 今天：开仓（卖 Call）/ 持有不动 / 减仓
```

> 卖 Call vs 卖 Put 的关键差异在第 3 条：杠杆效应天然不对称——跌时 IV 跳得比涨时猛。所以**卖 Call 的 Vega 风险天然比卖 Put 小**（上涨恐慌弱于下跌恐慌）。这是卖 Call 的结构性优势。

### HV 期限结构 + 量价真伪 + 信号冲突（同卖 Put）

> 见卖 Put 对应章节。规则不变：HV₂₀−HV₆₀ > 3% 不开新仓，缩量虚高可卖，放量真贵不追。信号冲突处理同上。

## C-四、离场决策（卖 Call 专用）

> 每天检查持仓时依次走一遍。任意一步触发 → 平。

### 开仓即写死止盈价

- 止盈 ¥ = 收的 credit × 50%（和卖 Put 一样）
- 规则不变：数字事先定死，盘中只执行。

```
1. 浮盈 ≥ 最大利润 × 50%？
      ↓ 是 → 平
      ↓ 否
2. 期货涨破买腿行权价？
      ↓ 是 → 平（和卖 Put 方向相反：卖 Put 看跌破，卖 Call 看涨破）

      ↓ 是 → 平
      ↓ 否
4. 两腿都实值（期货 > 卖腿行权价）？
      ↓ 是 → 平
      ↓ 否
5. OTM < 1% + 期货在上涨？
      ↓ 是 → 平
      ↓ 否
6. D-0/D-1 高影响事件？
      ↓ 是 → 平
      ↓ 否
  持有。明天再走一遍。
```

### 平仓顺序（同卖 Put）

- 先买平卖腿，后卖平买腿（避免短暂裸卖）
- 深实值 → 两条腿同时挂

## C-五、事件日历（同卖 Put）

| 事件距离 | 卖 Call | 
|---------|--------|
| D-0 到 D-1 | 不做 |
| D-2 到 D-7 | 可以，注意 ⚠️ 标记 |
| D-7+ | 正常 |

## C-六、禁止清单（卖 Call 专用）

- 不分腿下单 → 用文华财经组合单
- 不在事件前做卖方
- 不裸卖。任何情况下。
- 不在近值（OTM < 2%）进场
- 不因为"账户闲着"而强行下单
- **期货在上涨趋势中不做卖 Call**（趋势是你的敌人，跌时也一样——**期货在下跌趋势中不做卖 Put**）
- ITM 信用价差不做

## 卖 Put vs 卖 Call 速查

| | 卖 Put 价差 | 卖 Call 价差 |
|------|-----------|-----------|
| **方向** | 赌不跌 | 赌不涨 |
| **OTM 公式** | (期货 − 卖腿) / 期货 | (卖腿 − 期货) / 期货 |
| **危险方向** | 期货下跌 | 期货上涨 |
| **5 天检查** | 最低价跌破卖腿？ | 最高价涨破卖腿？ |
| **杠杆效应** | 跌时 IV 跳 → Vega 风险大 | 涨时 IV 跳弱 → Vega 风险小 |
| **结构性优势** | 商品有天然上涨偏向 | 杠杆效应不对称，IV 风险更小 |
| **Θ + Vega** | 相同 | 相同 |
| **事件规则** | 相同 | 相同 |
| **止盈 50%** | 相同 | 相同 |

# 买 Call 信用价差（Bull Call Debit Spread）

> ⚠️ 买方 = Theta 是敌人，Gamma 是朋友。逻辑与卖方完全相反。
> 买 Call 价差 = 赌期货涨过某个价位。付权利金，赚方向+Gamma。

---

## B-一、持仓监控：三档体系（买 Call 专用）

| 档位 | OTM 距离 | 触发条件 | 行动 |
|------|---------|---------|------|
| 🟢 正常 | < 3% | 任何情况 | 不动，等方向 |
| 🟡 警戒 | 3-5% | 期货在下跌 + 到期 < 20 天 | 评估 Theta 损耗。浮亏 > 40% → 可平 |
| 🔴 高危 | > 5% | 期货下跌 + Theta 加速 | 平。买方的钱是 Theta 扣走的 |
| ⛔ 撤离 | 到期 < 5 天且未触发 | 无条件 | 平。最后几天 Theta 指数级加速 |

### B-OTM 公式

```
买 Call OTM = (卖腿 − 期货) / 期货   ← 期货需涨到卖腿以上才赚钱
买 Put OTM  = (期货 − 卖腿) / 期货   ← 期货需跌到卖腿以下才赚钱
```

> 买方 OTM 方向 = 同卖方（Call 方向期货<卖腿，Put 方向期货>卖腿）。区别在于买方要期货**往有利方向走够远**，卖方只要期货**别往不利方向走**。

---

## B-二、进场环境定性（买 Call 专用）

> 买方看 IV 低位 + 事件催化。低 IV = 便宜保险，事件 = 跳空可能。

| # | 检查内容 | 🟢 有利（买 Call） | 🔴 不利（买 Call） |
|:--:|------|------|------|
| 1 | IV 分位 | IV < 30% → 期权便宜，买方成本低 | IV > 50% → 太贵，不值得买 |
| 2 | 事件距离 | D-2 到 D-7 有高影响事件 | D-0/D-1 → 市场已定价，IV 可能已被推高 |
| 3 | 方向判断 | 基本面/技术面支持上涨 | 无明显方向 → 买方不值得（方向对才赚） |
| 4 | HV 趋势 | HV 在涨 → 波动聚集，买方有利 | HV 在跌 → 低波动，方向不容易走出来 |
| 5 | ATM 流动性 | 价差 < 10% | 价差 > 15% → 买太贵，滑点吃利润 |

```
[1] IV 分位：___%  → 便宜/合理/贵
[2] 事件距离：D-___  
[3] 方向判断：看涨 / 看跌 / 无方向
[4] HV 趋势：涨 ⬆ / 跌 ⬇ / 平 ➡
[5] ATM 价差：___%

→ 有利 _/5  不利 _/5  → 今天：进场 / 等 / 不做
```

## B-三、进场决策（买 Call 专用）

```
1. Scanner --buyer 出买 Call 价差信号
      ↓
2. IV < 30% 分位？（买方黄金窗口）→ 否 → 等
      ↓ 是
3. 有方向判断吗？（为什么看涨？）
      ↓ 无 → 不做。买方不是赌，是对方向有判断
      ↓ 有
4. 有事件催化吗？（D-2 到 D-7）
      ↓ 有 → 加分。没有也可以做，但仓位减半
      ↓
5. OTM 选择：近值（<3%）→ Gamma 大、成本高。虚值（3-5%）→ 便宜但需要更多方向
      ↓
6. 赚什么钱？说出来再下单
   → 方向对（Delta）+ Gamma 加速 + Vega↑（事件后 IV 涨）
   （说不出来 → 不做）
      ↓
7. 做。仓位 ≤ 卖方仓位的 50%（买方胜率低，小仓位）
```

---

## B-四、离场决策（买 Call 专用）

```
1. 方向对了，浮盈 ≥ 成本 × 100%（翻倍了）？
      ↓ 是 → 平一半锁利，留一半跑
      ↓ 否
2. 事件落地了（D+1）？
      ↓ 是 → 评估：方向触发了吗？触发→持有，没触发→平（IV 要跌）
      ↓ 否
3. 剩余 ≤ 10 个交易日？
      ↓ 是 → Theta 加速。没触发就平，别等归零
      ↓ 否
4. 浮亏 ≥ 成本 × 50%？
      ↓ 是 → 方向判断可能错了。平
      ↓ 否
5. IV 暴涨了（Vega 赚了）？
      ↓ 是 → 可以平了锁 Vega 利润 + 方向利润
      ↓ 否
  持有。明天再走一遍。
```

---

## B-五、禁止清单（买 Call 专用）

- IV > 50% 分位不做（太贵）
- 没有方向判断不做（纯赌方向 = 买方的"凭直觉赌方向"）
- D-0 当天不买（事件马上落地，IV 可能已被推高）
- 不追涨：已经涨了一大段才买 = 方向可能已经定价
- 买方仓位 ≤ 卖方仓位的 50%（买方天然胜率低）
- 买方不做"摊平成本"（亏损加仓 = 赌徒）

## 无信号日操作规程

> 当日 Scanner [EXEC] = 空 + 五条卡不满足 ≥3/5 有利 → 触发本规程。执行以下至少一项，写一句话进 journal。

### ① 历史归因复查
- 从 `trade_log.md` 随机抽一笔历史交易
- 重读当时的进场逻辑和离场结果
- 问自己：*现在回头看，当时该做吗？*
- 写一行答案进当日 journal

### ② 尾部事件推演
- 从 `docs/tail-events.md` 随机选一个事件
- 用今天的 IV 数据推演：*如果今天发生类似事件，假设持有标准仓位（OTM 3% 卖 Put 信用价差），会怎样？*
- 推演结果写一句进 journal

### ③ 干旱碎片
- 为什么今天没信号 本身就是一条影响力碎片
- 例：连续第5天无EXEC，IV全线<P30——卖方在冬眠等春天

## 无信号干旱计数器

### 定义
- **无信号日**：Scanner [EXEC] = 空，且五条卡不满足 ≥3/5 有利
- **计数**：按交易日连续累计。周六复盘不归零（只记不罚）
- **有信号当天**：计数器归零

### 升级规则

| 连续天数 | 动作 |
|---------|------|
| 0-4 | 正常。无信号日操作规程照做。 |
| 5-9 | 回顾 Scanner 参数——OTM 阈值、IV 分位门槛是否过严？不动参数，只写判断入 journal。 |
| ≥10 | 系统排查——是 IV 环境长期不利？合约换月空窗？Scanner bug？抽查一个品种手动计算 vs Scanner 输出。结论入 journal。查到 bug 再修。 |

> 干旱本身是数据。不因为干就降低标准——但到了阈值必须自动升级排查，不能干等。
