# 卖方干净窗口基准率跟踪

> 立：2026-09-08。目的：回答「四层全绿的卖方窗口多久出现一次」——是常态还是倒霉。
> 检查点：**2026-12-17**（约 4 个月）。届时月均干净窗口 <1 → 结构假设坐实，上质疑轮谈策略形态；只是夏秋挤 → 数据自证「这是季节」。
> 每个有卖方 EXEC 信号的交易日，收尾归一行。诚实优先——宁可归「无法归类」，不硬塞。

## 分类（每个 EXEC 交易日只归一类）

| 类 | 定义 | 意义 |
|----|------|------|
| **A 窗口·开了** | 四层全绿 + 真开仓（含虚拟，注明） | 真窗口，接住了 |
| **B 窗口·没开** | 四层全绿但没开（当时理由多好听都算） | **危险类**：市场给了你没接 = 恐惧/纪律假绿。月底数它 |
| **C 毙于硬规则** | 写出**唯一主毙层**（倒挂/事件层/IV分位真贵/资金rr/重复开仓/环境） | 非窗口，市场没给 |
| D 无 EXEC | 不计 | 只标交易日 |

**防自欺铁律**：C 必须写得出唯一主毙层，且那层是 monitoring-rules 里的硬规则，不是「感觉/不太对」。**写不出唯一层 = 归 B，不许归 C。**

## 真窗口口径（给 12/17 判定的数）
- **月均窗口 = (A+B)/月**。A/(A+B) = 接单率——B 高而 A 低 = 纪律假绿或恐惧，不是市场问题。
- 数据可回溯起点 **2026-08-13**（D 门逐日 EXEC 评估从这天起稳定）。6/24-8/13 在建系统（无逐日四层评估），**不计入基准率**。
- 8/14 cf2701 那次"开"：事后证伪其进场 IV-HV 依据是污染数据（真实 +0.43%<1%），**非干净窗口**，记 A 但注明。
