## 挑信号：两关一判（7/24 重构）

> 旧版三条平级，趋势只是"有就行"→ 纸面追踪 12 笔 11 亏，根源：不动=Theta 吃完所有便宜。
> 新版：趋势前置门。IV 便宜 + 盈亏比高但标的横盘 = 不记。

### 第一关：标的在动吗？（不过关直接跳过）

- 5 日涨/跌幅 ≥ 1%（方向明确）
- 或 D-7 内有 Tier 1 事件（真催化，不包含 USDA 周报等例行）
- → **不过关 = 跳过。IV 再便宜也不看。**

### 第二关：IV 便宜吗？

- 买方价差：ScP ≤ 25（有卖腿对冲，可稍贵）
- 买单腿：ScP ≤ 15（全裸 Vega，必须极便宜。IV 回落=双杀）

### 第三判据：盈亏比够厚？

- 买方价差：RR ≥ 5:1
- 买单腿：不硬性要求 RR（理论盈利不封顶，无法精确算）→ 改为：权利金 ≤ 本金 2% + OTM 5-15%

两关全过 + 判据达标 = ⭐⭐⭐。过一关 + 判据达标 = ⭐⭐。过第一关、IV 偏贵但 RR 极高 = ⭐（记入对照组，不分星级）。

> 📊 7/24 回测：白糖买P 7/17（横盘 0.3%，第一关不过）→ 如果当时有这规则会直接跳过，不用吃 7 天 Theta 亏损。

### 停止追踪（8/5 初版 → 8/18 加退出线）

| 退出条件 | 为什么 | 动作 |
|---------|--------|------|
| 合约到期 | DTE→0 | 标记 [到期]，周六填结果 |
| **DTE ≤ 15 天（8/18 新增）** | 追到交割=惯性，只会重复"无法平仓"；流动性退化前就该结算 | 标记 [近到期]，写盈亏 → 归档文末 |
| **追踪满 2 周、第一关趋势未兑现（8/18 新增）** | 纸面=模拟仓位，要模拟退出压力。横盘=Theta 吃光，再追只重复已知结论 | 标记 [假设失效·X天]，写一句哪条判据不成立 → 归档 |
| 假设失效 | 趋势连续 3 天反向 >2%，或事件过了没动静 | 标记 [假设失效·X天后]，写一句：哪条判据不成立 |

**迁移（仅限少数，8/18 定）**：纸面结算后**一般不迁移**。只有逻辑还活着（趋势同向 + 催化未过期）+ 新主力月流动性够的，才在新主力月开新条目，注明 `[迁移自旧合约]`。多数信号死在 2 周内就该结算，走不到交割。

> 8/18 教训：2609 系 30 条追了 1 个月到"无法平仓"，是没退出线的代价——纸面也是仓位，要像真仓位一样到点就平。
