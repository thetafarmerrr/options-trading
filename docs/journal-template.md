# 每日 journal 模版（原始框架 8/14 版，8/26 固化）

> **单一真相源**：每天收尾按此结构写 `journal/YYYY-MM-DD.md`。
> **必写三段**：今日反思 / 明日待办 / 今日学到。其余段当天没发生就跳过，不硬凑。
> 结构乱是格式问题，按此搬；用户笔记不删不改。
