## 每日（~20 min）

| 步骤 | 内容 | 方式 | 预计 |
|------|------|------|------|
| 6a. 视频 | 按下方观看顺序，每天从上次停的地方继续 **1 集**，不选 | ① 看画面+字幕抓大意 → ② 张嘴跟读不停。不重播不查词 | 15 min |
| 6b. 挖矿 | 从刚看的视频里抓 3 个整句，追加到 `glossary.md` 底部 `## 句型库` | 按场景分组，格式见下 | 2 min |
| 6c. 炸弹 | 刚看的视频说了什么，张嘴 90 秒，不停不改不查词 | 录 → 语音转文字 → 瞥一眼差异（不修改，只是看）| 3 min |
| 6d. 笔译 | 当日扫描结论或阅读摘要译英文，2-3 句 | — | 2 min |

## 挖矿格式（追加到 glossary.md 底部）

```
## 句型库（每日 Mike 挖矿，按场景分组）

### 表达"不确定但准备行动"
- We'll see how it plays out.  （Mike E07, 8:15）

### 描述价格运动
- It's been grinding higher for two weeks straight.  （Mike E12, 3:40）
```

场景名用已有的，没有就新建。每次追加 3 句。
