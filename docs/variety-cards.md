### 二、⚠️「13%」不是「卖期权占 13%」——期权走**另一个公式**

大商所 / 郑商所 / 上期所 / 能源中心 / 广期所 **公式完全一致**（该 PDF p3–p5）：

```
期权卖方保证金 = 两者取大
（一）期权价格 × 交易单位 + 标的期货[公司]保证金 − ½ × 虚值额
（二）期权价格 × 交易单位 + ½ × 标的期货[公司]保证金

其中  标的期货[公司]保证金 = 期货价 × 合约乘数 × 上表公司率
      看跌期权虚值额 = max(期货价 − 行权价, 0) × 合约乘数
      （虚值额定义：该 PDF 未展开，取通用定义，**需另核**）
```

**（二）就是地板，但触发条件很苛刻**：只有当 **虚值额 ≥ 标的期货保证金** 时才生效
→ 即 `|行权价 − 期货价| × 乘数 ≥ 标的期货保证金`。
**S1 的常规虚值卖腿拿不到地板**，实际占用明显更高。

**例（铁矿石 i2701 @ 712，标的期货保证金 13,528）**：

| 卖出 put | 虚值额 | 卖方保证金 |
|---|---|---|
| P700 | 1,200 | 权利金 + 12,928 |
| P680 | 3,200 | 权利金 + 11,928 |
| P650 | 6,200 | 权利金 + 10,428 |
| P600 | 11,200 | 权利金 + 7,928 |
| **P576 及以下** | ≥13,600 | 权利金 + **6,764**（地板） |

→ **地板要虚值 135 点以上才够**。换句话说：**÷2 是个几乎用不到的下界。**

**出处**：Ch5 Implied Volatility Dynamics，书页 75–79 / PDF 91–95。earnings 周期上**多跨式 vs 空跨式**的实证。

空跨式那条**反直觉**，Sinclair 给两个机制：
1. 高分歧 → IV 被推高 → **卖方卖在好价钱**
2. 高分歧 = 分析师（进而市场）**没有一致预期** → **没有共识，就不存在"意外"** → 实际跳空反而温和 → **利于卖方**

**⚠️ 机制②与本卡上方"双尾分布 → 做多波动率最适配"的推理方向相反。**

**分界线（教练自拟，未验证）**：关键是**事件本身是否已被确定会发生**——

- **未预定**（lc 的政策 / 产能突发）→ 分歧大 = 真会挨打 → **利买方**

**⚠️ 上面这条分界线是推理，不是实证。** Sinclair 未讨论"未预定事件"，等于教练用自造的类别在保自己的结论。**要定案需回到 lc 涨停历史，逐个检验每次涨停能否追溯到事先已知的事件**——数据活，未做。

### 成本 / 供给来源
```
进口大豆（巴西 / 美国） → 油厂压榨 → 豆粕（+ 豆油，副产品）
```
**豆粕的定价核心变量 = 进口大豆到港量 + 油厂开机率 + 下游养殖需求**，而**大豆供给又高度依赖美国/南美**。
**注意与 PTA 的对比**：PTA 的成本来自**原油**（单一上游），豆粕的成本来自**农作物**（天气 + 贸易政策双驱动）→ **事件类型完全不同**。

### 事件类型学：**三源并列**（这是它和 c/rm 归为一组的根据）
1. **美国报告**：USDA 作物生长进度（每周二早）· WASDE（月度）· 出口销售 · 收割进度
2. **中美贸易**：采购量 · 关税/降税磋商 · 贸易休战期限
3. **南美天气**：厄尔尼诺 · 巴西/阿根廷产情（Conab 等）
4. 国内：油厂开机 · 大豆到港 · 豆粕库存 · 养殖需求

### 季节性
**美豆生长季（6–8 月）= 天气市**；**9–11 月 = 收割压力 + 南美播种**；**12–2 月 = 南美天气市**。
当前（9 月）正处 **美豆收割期** → 供给端压力为主基调。
